# Personal Portfolio Website

A personal portfolio website created to introduce my background, highlight my technical skills and projects, and provide visitors with a way to contact me. The website is deployed on Vercel.

## 🌐 Live Website

[Visit my portfolio](http://portfolio-lovat-kappa-22.vercel.app/#contact)

## 📌 Project Overview

This project presents my personal and academic profile in one place. It is intended to showcase my learning journey, technical skills, and completed projects through a portfolio website.

## ✨ Website Sections

- **Home** — Introduction and welcome section.
- **About Me** — Personal and educational background.
- **Skills** — Technical skills and areas of learning.
- **Projects** — A collection of projects with descriptions and repository links.
- **Contact** — Contact information and ways to connect.

## 🧩 Project Requirements and Features

The portfolio assessment calls for the following features:

- Personalized profile and introduction.
- Project cards with descriptions, technologies, and repository links.
- Search and filter functionality to find projects by name or technology.
- Light and dark theme toggle.
- Responsive layout for desktop and mobile screens.
- Deployment through Vercel.

## 🛠️ Technologies and Tools

The assessment uses the following tools and technologies:

- HTML
- CSS
- JavaScript
- Git and GitHub
- Cursor AI
- Vercel

## 📂 Projects

The assessment requires a portfolio section containing these five projects:

1. **Python Programs Collection** — Python programs including factorial, Fibonacci, and structure-to-dictionary conversion.
2. **Messy Python Code Improvement** — A Python script improved with AI assistance.
3. **Bug Fixing Using Cursor AI** — A buggy program examined and corrected using Cursor AI.
4. **Interactive Quiz Application** — A quiz application developed as part of the coursework.
5. **Book Reading List Application** — A reading list application with an updated README that includes its deployed link.

## ☁️ Deployment

The portfolio is published on Vercel:

[http://portfolio-lovat-kappa-22.vercel.app/#contact](http://portfolio-lovat-kappa-22.vercel.app/#contact)

To deploy updates:

1. Commit and push the changes to the connected GitHub repository.
2. Confirm that the repository is connected to the correct Vercel project.
3. Wait for the deployment to complete.
4. Open the live website and check navigation, project links, responsive layouts, search/filter behavior, theme toggle, and chatbot functionality.
